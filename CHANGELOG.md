# Changelog

## 0.1.2 — Opt-in send-back formats

- Removed automatic funny and serious reply generation from the arbiter contract.
- Kept humor in the evidence-led readout and made outbound messages opt-in.
- Added short Slack or Teams, professional revision-request, and blunt send-back options.

## 0.1.1 — Funny reply acceptance

- Required funny-mode draft replies to contain an artifact-specific comic turn.
- Added punchier, workplace-safe patterns including short reactions such as “Seriously, bruh?”
- Added regression checks that keep funny and serious replies distinct.

## 0.1.0 — Private release candidate

- Added the blinded baseline and cold-reader review panel.
- Added Human delta, reader-burden, trust, and AI-residue checks.
- Added funny and serious draft responses.
- Added Agent Plugin and Claude/Cowork packages from one runtime source.
